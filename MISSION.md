# Mission: Agentic engineering

## Why
Tawanda is a software engineer building web applications and developer tooling. He wants to direct LLM coding agents so the output is reviewable, correct and small enough to own, without his own engineering skills atrophying.

## Success looks like
- Explain why agent sessions degrade as context grows, and choose between clearing, compacting, delegating to a subagent and verifying
- Structure a task so an agent works within a bounded context and a human can review the result
- Use AI in ways that keep him learning (comprehension, debugging) rather than only delegating
- Write lean project instruction files and verification loops for his own repos

## Constraints
- Learns sequentially: each idea builds on the last
- Prefers Mermaid for diagrams

## Out of scope
- Building agents from scratch as a product (for now); model training internals
