A self-paced course

Agentic engineering

Using LLM coding agents to build web apps and developer tooling without producing slop, and without your own skills atrophying. Taught sequentially: each lesson builds on the last. Lessons use Mermaid diagrams loaded from a CDN, so open them with an internet connection.

Mission

  • Explain why agent sessions degrade as context grows, and choose between clearing, compacting, delegating and verifying
  • Structure tasks so an agent works in a bounded context and a human can review the result
  • Use AI in ways that keep you learning, not only delegating
  • Write lean project instruction files and verification loops for your own repos

Full text in MISSION.md.
